# Hifazat Guide — Delivery Checklist

## Public-facing information architecture
- [x] The site introduces Hifazat Guide as a student-led child rights, safety and protection initiative for children aged 9–15 in Pakistan.
- [x] The site gives children, parents, teachers and schools distinct pathways to find relevant information and next steps.
- [x] The site includes clear calls to learn more, participate as a school, or start a general conversation.

## Urdu-first learning experience
- [x] The site explains that language, examples and presentation are adapted for accessibility, cultural relevance and an Islamically respectful classroom context.
- [x] The experience includes readable Urdu support and a visible language toggle without requiring a framework or external app.

## Four-session classroom programme
- [x] The site presents four age-appropriate sessions: Understanding Rights & Dignity; Personal Boundaries & Unsafe Situations; Discipline vs Abuse; and What To Do & Who To Approach.
- [x] Each session communicates its purpose in plain, non-graphic language and reinforces safe help-seeking.

## Pilot timeline and delivery model
- [x] The site shows the pilot journey from research and development through school sessions and report/advocacy.
- [x] The site names the planned pilot schools from the source plan without implying results beyond the implementation plan.
- [x] The site communicates delivery standards including counsellor/teacher presence, trained student volunteers, emotionally safe content and no sensitive disclosures in surveys.

## Safeguarding and impact
- [x] The site covers child-centred participation, privacy, appropriate boundaries, consent and responsible escalation.
- [x] The site explains pre/post assessment, anonymous questionnaires, structured feedback and aggregated reporting without overstating outcomes.
- [x] The site clearly distinguishes learning measurement from collecting personal or sensitive disclosures.

## Responsive accessible implementation
- [x] The site uses plain HTML, CSS and JavaScript with responsive navigation, semantic landmarks, keyboard-friendly controls and reduced-motion support.
- [x] The project includes a valid `/manus-routes.json` route manifest and runs on the configured preview port.
- [x] No AI, generator, framework or author branding appears in the public experience.
